# Home Sections

Homepage-only sections live in this folder.

Current structure:

- `hero` - homepage hero, background slides, title, and search bar.
- `top-categories` - trek category cards and view-all action.
- `our-partners` - partner intro and partner carousel.
- `featured-destinations` - featured trek destination cards.
- `why-trek-with-us` - trust and benefit content.
- `snapshots` - travel photo carousel.
- `our-testimonials` - customer testimonial content.
- `cta` - final homepage call-to-action section.

Shared components should stay in `src/components/layout`.
